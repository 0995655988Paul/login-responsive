# Login responsive - AdminExpress

Actividad de Ingeniería Web. Réplica de la referencia usando HTML y CSS.

## Abrir

Abre `index.html` en Safari o Chrome. No necesitas PHP ni instalar dependencias.

## Estructura

- `index.html`: marca, formulario, campos y enlaces.
- `styles.css`: CSS Grid, colores, espaciado y media queries.

## Adaptación

- Escritorio: dos columnas, marca azul y formulario.
- Tableta (hasta 1024 px): columnas con proporción 42/58.
- Móvil (hasta 600 px): una columna, marca oculta y botón completo.

El correo usa la validación HTML de `type="email"`; ambos campos son obligatorios y la contraseña requiere al menos ocho caracteres. Esta actividad es una maqueta visual: no autentica usuarios. El ojo es decorativo y los enlaces de recuperación y registro no tienen funcionalidad. La contraseña no se envía en la URL.
